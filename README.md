# PlainArmor static copy

A static copy of the PlainArmor web app (home page, policy pages, support, about, pricing and the help pages), exported from the app on 2026-11-12 and published with GitHub Pages at plainarmor.com. Stripe's verification code was removed on 2026-11-13 once Stripe approved the account.

Forms (code box, support, unsubscribe) need the app's server, so here they show a short note to email support@plainarmor.com. Replaced by the real app at go-live (PA-11).

To refresh: run the app in production mode locally, re-run the export, commit and push.
